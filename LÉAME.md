# App de Perfiles de Usuario

Aplicación web moderna y dinámica diseñada con enfoque en el usuario. Las herramientas, estructura y tecnologías usadas responden a estándares web actuales y una interfaz "premium" optimizada en rendimiento.

## 🚀 Tecnologías

- **HTML5:** Marcado semántico.
- **CSS3:** Patrón de diseño UI con Glassmorphism, variables (CSS custom properties) y diseño "mobile-first".
- **Vanilla JS:** Manejo del DOM, navegación e interacciones simuladas de actualización de perfil usando `localStorage`.

## 📂 Estructura de Directorios

```text
/Web_pro
│
├── LÉAME.md              # Documentación del proyecto
├── index.html            # Página de Inicio
├── sobre.html            # Página de Perfil / Sobre
├── servicios.html        # Página de Servicios
├── contacto.html         # Página de Contacto
├── css/
│   └── estilos.css       # Biblioteca de estilos visuales
├── js/
│   └── app.js            # Lógica dinámica y persistencia
└── img/
    ├── logo.png          # Logo de la app (generado por IA)
    └── avatar.png        # Foto de perfil demo (generada por IA)
```

## 🔧 Instalación y Uso

1. Ubique la carpeta `Web_pro`.
2. Abra `index.html` en cualquier navegador web moderno (se recomienda Google Chrome, Firefox, Safari o Microsoft Edge).
3. Todo es un entorno local, así que la interactividad como el "guardado" de perfil funcionará directo al usar `localStorage`.

## ✨ Características Premium
- **Glassmorphism:** Efectos difuminados modernos.
- **Dark Mode Vibrante:** Estética oscura muy pulida con fuentes de luz de colores.
- **Micro-animaciones:** Transiciones y respuestas a las iteraciones del usuario en todos los botones y campos interactivos.

_Proyecto creado con IA generativa para suplir recursos visuales y código estructurado robusto._
