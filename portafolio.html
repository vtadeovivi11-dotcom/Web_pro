1. Implementación Arduino: Alarma de Sirena

Este proyecto utiliza un sensor ultrasónico para medir distancia. Si un objeto se acerca a menos de 5cm, el zumbador (buzzer) se activa emitiendo una frecuencia alternante (alarma), y envía la información a través del monitor serial. 

// Definición de pines
const int pinBuzzer = 8;
const int pinTrig = 9;
const int pinEcho = 10;

void setup() {
  pinMode(pinTrig, OUTPUT);
  pinMode(pinEcho, INPUT);
  pinMode(pinBuzzer, OUTPUT);
  Serial.begin(9600);
  Serial.println("Alarma de Sirena Iniciada...");
}

void loop() {
  // MIDE LA DISTANCIA
  digitalWrite(pinTrig, LOW);
  delayMicroseconds(2);
  digitalWrite(pinTrig, HIGH);
  delayMicroseconds(10);
  digitalWrite(pinTrig, LOW);

  long duracion = pulseIn(pinEcho, HIGH, 30000);
  float distancia = (duracion == 0) ? 999 : duracion * 0.0343 / 2;

  // LÓGICA DE ALARMA
  if (distancia > 0 && distancia <= 5.0) {
    tone(pinBuzzer, 800); delay(200);
    tone(pinBuzzer, 1200); delay(200);
  } else {
    noTone(pinBuzzer);
    delay(150);
  }
}

3. Fundamentos Físicos de las Ondas

Las oscilaciones en la naturaleza (como el sonido y la luz) se representan matemáticamente usando trigonometría pura. A este tipo de representaciones armónicas se les conoce como el estudio de Seno, Coseno y Tangente.

¿Qué son y por qué suceden?

Las razones trigonométricas (Sen, Cos, Tan) describen las relaciones entre los lados de un triángulo rectángulo circunscrito en un Círculo Unitario. Cuando un punto da la vuelta lentamente alrededor de ese círculo en el tiempo (un movimiento circular uniforme), la variación de su altura a lo largo del tiempo dibuja sistemática y perfectamente un patrón ondulado: La onda senoidal. Es por esto que los péndulos, resortes y ondas comparten estas ecuaciones.

  • Seno (Sen): Representa el valor en el eje 'Y' (vertical) del círculo. Su onda comienza partiendo del origen $0$.
  • Coseno (Cos): Representa el valor en el eje 'X' (horizontal). Si dibujas su onda en el tiempo, comienza desde su punto de amplitud máxima $1$. Es la misma onda del Seno, solo que desfasada por 90 grados.
  • Tangente (Tan): Es el cociente entre el Seno y el Coseno. Su onda no es uniforme ni continua, ya que en ciertos ángulos el Coseno se vuelve cero, lo cual dispara la gráfica hacia el infinito en patrones repetitivos conocidos como asíntotas.
